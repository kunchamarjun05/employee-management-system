## 🌐 Live Demo

🔗 **[View Live App](https://kunchamarjun05.github.io/employee-management-system/)**

---

## ✨ Features

- 🔐 **Secure Login** — Authentication with form validation
- 👤 **Employee CRUD** — Add, Edit, Delete & View employees
- 📊 **Dashboard** — Overview with employee statistics
- 🔍 **Search & Filter** — Find employees quickly
- 🎨 **Modern UI** — Clean, professional interface
- 📱 **Responsive** — Works on desktop and mobile
